# 1-800 Cash For Cars

Landing page for a cash-for-cars offer flow with responsive navigation, mobile contact actions, bilingual English/Spanish routing, and branded assets from `public/logo.svg`.

## Routes

- English: `http://127.0.0.1:3000`
- Spanish: `http://127.0.0.1:3000/es`

## Development

```bash
npm run dev
```

Open `http://127.0.0.1:3000`.

## Checks

```bash
npm run lint
npm run build
```
